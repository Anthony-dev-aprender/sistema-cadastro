# Cadastro de Colaboradores

Projeto desenvolvido em PHP para cadastro de novos colaboradores das Lojas Brincos e Companhia.

O sistema possui um formulário para informar nome, idade, profissão, salário pretendido e experiência anterior. Os dados são enviados pelo método **POST** para o PHP, que processa as informações e apresenta uma página de confirmação personalizada.

O projeto foi desenvolvido utilizando **HTML, PHP e CSS**, com execução local através do **XAMPP e Apache**.
